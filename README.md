# Online Food Ordering System - Builder Pattern

## Description

This Java project demonstrates the classic Builder Design Pattern
using delivery and pickup food orders.

## Pattern Structure

- Product: Order
- Builder: OrderBuilder
- Concrete Builders:
  - DeliveryOrderBuilder
  - PickupOrderBuilder
- Director: OrderDirector
- Client: Patternnproj

## Project Files

- Order.java
- OrderBuilder.java
- DeliveryOrderBuilder.java
- PickupOrderBuilder.java
- OrderDirector.java
- Patternnproj.java

## How to Run

Run `Patternnproj.java` from NetBeans.
